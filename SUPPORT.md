# Help and feedback

Start with the [decision guide](README.md#start-with-your-decision) or browse the [founder guides](guides/README.md), [research](research/README.md), and [conference collections](conferences/README.md).

- **Corrections, broken links, or questions about the library:** [open an issue](https://github.com/savvides/scaleu-intelligence/issues/new/choose). Include the page, the problem or question, and a public source where relevant.
- **A useful source or proposed addition:** use the source suggestion template, explain who it helps, and follow the [contribution guide](CONTRIBUTING.md).
- **Private information or a security concern:** follow [SECURITY.md](SECURITY.md). Do not copy sensitive material into a public issue.
- **Edtech partnerships or institutional pilots:** contact [ASU ScaleU](https://scaleu.org).

Philippos Savvides maintains this library. Responses depend on maintainer availability. Issue discussions are public, so share only information you have permission to publish.
