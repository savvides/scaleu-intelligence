# Founder guides

[ScaleU Intelligence](../README.md) / Founder guides

Use these guides to work through a decision, then follow the references for the evidence behind it. The collection began as EdTech Founder Stack; original update dates remain in place.

Each folder answers one founder question. To add a guide, put it in the folder whose question it answers and add a line below. Add a new folder only for a question none of these cover.
