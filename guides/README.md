## How to read these guides

Guides keep four kinds of evidence apart: research findings, laws and official statistics, speaker claims, and practitioner estimates. Each guide ends with the date its facts were last checked and what the check covered. Regulations, program terms, and company status change; confirm them at the linked primary source before you act.

To add a guide, put it in the folder whose question it answers and add a line above. See the [contribution guide](../.github/CONTRIBUTING.md). Licenses differ by collection; see [LICENSE.md](../LICENSE.md).
