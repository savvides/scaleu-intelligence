# Sources

[ScaleU Intelligence](../README.md) / Sources

The original evidence behind the [guides](../guides/README.md). Each collection keeps its source's context, dates, and attribution. Start with a guide, then follow its links here when you need the detail.

| Collection | What it holds |
|---|---|
| [Learning research](research/README.md) | 19 topics, 376 paper entries with takeaways, study types, and DOIs |
| [Events](events/README.md) | Conference reports, deliverables, session indexes, and transcripts |
| [Field notes](notes/README.md) | Dated observations from meetings and other work |

Transcripts record what speakers said, not verified results. Research takeaways summarize the cited papers; read the paper for study design and limits.

To add a new kind of source, create a folder here with a README that indexes its files, then add a row to this table.
