# JTBD switch data

[ASU+GSV 2026](../README.md) / JTBD switch data

Structured switching-behavior analyses behind round one of [Why Education Leaders Are Switching](../deliverables/demand-signals.md). Each file reconstructs one switch described on a summit panel: the push away from the old approach, the pull toward the new one, the anxieties, and the habits. All five are secondary evidence from panel conversations, not 1-on-1 Switch interviews, so treat the patterns as hypotheses to test.
